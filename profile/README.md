# Agent Passport System

Open protocol for verifiable agent authority and action evidence. A person or company gives an AI
agent limited authority to act on its behalf; the protocol checks that authority before an action
and produces signed evidence of what the agent did with it. Apache-2.0.

- Protocol and TypeScript reference: [agent-passport-system](https://github.com/aeoess/agent-passport-system)
- Language implementations: [Python](https://github.com/aeoess/agent-passport-python), [Go](https://github.com/aeoess/agent-passport-go), [Rust](https://github.com/aeoess/agent-passport-rust)
- MCP server: [agent-passport-mcp](https://github.com/aeoess/agent-passport-mcp)
- Vocabulary registry: [agent-governance-vocabulary](https://github.com/aeoess/agent-governance-vocabulary)
- Conformance suite (an LF Decentralized Trust lab): [Agent-Authority-Conformance/aps-conformance-suite](https://github.com/Agent-Authority-Conformance/aps-conformance-suite)
- Standards and research: [draft-pidlisnyi-aps](https://datatracker.ietf.org/doc/draft-pidlisnyi-aps/), [papers](https://agent-passport.org/research.html)

Versions, counts and test totals are read from the package registries and CI, never written here.
